# UnderBox 产品演示播放器

独立的 1920 × 1080、16:9 时间轴演示，默认 177 秒。启动后不调用模型、检索服务或外部 CDN；镜头、字幕与原创合成音乐由同一个播放时钟驱动。

## 启动

在服务器上：

```bash
cd /opt/underbox-repo/demo-video
python3 -m http.server 8795 --bind 127.0.0.1
```

通过 SSH 端口转发后打开：

```bash
ssh -L 8795:127.0.0.1:8795 root@8.208.14.251
```

浏览器访问 `http://127.0.0.1:8795/`。也可以下载完整文件夹后直接打开 `index.html`。Chrome、Edge 或其他支持 Web Audio 的现代浏览器均可使用。

## 播放与录制

点击「开始演示」后自动播放。底部控制栏支持暂停、继续、重播、拖动进度、章节跳转、字幕、配音辅助、音乐及音效开关和音量。音乐和音效通过浏览器本地合成，不依赖第三方版权音源；首次播放需要点击以激活浏览器音频。

点击「录屏模式」隐藏控制栏，画面保持 16:9；按 `Esc` 退出。空格暂停 / 继续，左右方向键跳转 5 秒。用 OBS 或浏览器录屏工具捕获页面并设置 1920 × 1080；如需录入合成音乐，请在录屏软件中启用浏览器 / 系统音频。先试录几秒以确认音频路由；录入自己的旁白时可降低音乐音量。

## 配音、字幕与时间轴

`narration.md` 按镜头列出起止时间、画面、可直接照读的中文旁白和音乐提示。`subtitles.srt` 是默认时间轴字幕。打开「配音辅助」可在画面右上角显示当前台词；录屏时请按需关闭，以免重复显示。

`timeline.js` 是唯一的默认镜头、字幕和时长配置。可修改每个镜头 `duration`、字幕相对 `start` / `end` 与文本；字幕应落在镜头时长内。调整后重新打开页面，并同步修改配音稿 / SRT。播放器的「调整时长」按钮允许逐镜头调整，进度与字幕按比例同步，设置保存在浏览器；点击「导出当前字幕」下载对应的 SRT。要恢复默认时长，清除该页面的本地存储。

## 素材与事实边界

`assets/overview.png`、`evidence.png`、`company.png`、`contacts.png` 和 `sample.png` 均为真实产品界面中使用合成履历和示例邮箱生成的画面；`upload.png` 截自真实上传入口。案例、邮箱、数据和截图内的覆盖数字均为演示用示例，画面标注「合成演示数据」，不代表真实人员或产品整体指标。工作流、拆分和规则画面标注为「技术原理示意」，模块名称和判断边界依据现有仓库代码。演示不产生新的核验结果。

录制前建议先检查素材文字、版权和隐私，再完整试听一次旁白与音乐。音乐为本项目生成的 Web Audio 音色，可关闭并在后期替换为自有授权音乐。
