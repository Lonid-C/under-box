# 实习单位资料

实习条目包含可追溯的单位介绍、注册地址、办公/联系地址、登记经营范围、主营业务和公开联系方式。
成立时间、注册编号、机构类型、资本、状态、规模等字段在取得对应资料后显示。
每个字段保留来源网址、标题、读取时间、原文摘录及提取方式；概述另标 `valueKind: summary`。

- `registeredAddress` 只读取明确的注册地址/注册办事处/住所标签。
- `officeAddress` 保留办公地址、联系地址和官网公司地址，与注册地址分别呈现。
- 历史登记记录须在字段标签注明披露年份，不能冒充当前登记情况。
- 企查查/天眼查可用精确企业详情或名称查询入口打开；平台客服不能成为企业联系人。
- 品牌官网的版权声明明确列出法律主体时，可以读取该主体的总机、邮箱和客服热线。
- 实习正文明确列出的驻企单位分别存入 `relatedCompanies`，同名或相近名称不自动归并。
- 单位资料进入问答和报告导出，但不会成为个人实习的证明或改变其核验状态。

验证使用虚构机构与号码：`cd open_box && python -m unittest tests.test_institution_context tests.test_source_replay`。
