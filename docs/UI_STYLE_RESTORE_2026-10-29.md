# 原版视觉恢复与保留功能

按用户要求恢复原来的 UnderBOX 风格：奶油色网格纸、洋红品牌色、粗黑边框、4px 圆角、硬阴影、大字标识、居中登录/上传布局，以及登录页拨云光斑。页面沿用 index.html 原有视觉变量和基础样式，ui.css 只保留新增交互组件及适配。

保留：
- 首次 Tour 及使用指南重播，Toast、Tooltip、来源/输入风险/账户抽屉、轻量确认与配额输入。
- boxy 像素素材、呼吸摇摆与思考状态，问答快捷键、问题建议。
- 水墨渐进流式回答、停止、复制、中文输入法保护与减少动态效果。
- 企业/院校补充资料、可选联网问答、报告导出与账户功能。

新组件统一采用原版黑边、洋红按钮和硬阴影。报告页 Tour 首个锚点改为实际顶栏，避免指向已隐藏的新工作台标题。boxy 素材与 InkStream 逻辑保持原样。

验证：
- ui.js 与全部内联脚本通过 node --check。
- node --test underbox/tests/test_ink_stream.cjs：5 项通过。
- 服务器临时预览使用明确标注的合成 fixture，不调用模型/搜索服务。
- 浏览器验证登录、首次/重播 Tour、来源抽屉、轻量确认取消、boxy 问答、复制 Toast、停止后保留已收内容。
- 1360px 桌面与 390px 手机检查；手机页面宽度 390px，无水平溢出，问答窗口未越界。
- 部署后比对三个静态文件的 HTTP 内容散列，检查服务和鉴权边界。

本次只改视觉及其引导锚点，不将前端检查表述为后端全量回归通过。历史浅色方案记录见 UI_REFRESH_2026-10-29.md。
