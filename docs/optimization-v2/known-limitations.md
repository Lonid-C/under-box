# Known limitations

## 2026-10-15 修复后现状

- **已通过全量离线回归**（core 544/544、service 42/42、legacy 29/33 含 4 项签名不变的旧失败、
  两个 `.cjs` 通过；见 `validation-report.md`）。以下才是仍然存在的边界。

## 验证边界

- 真实浏览器（桌面/900px/390px）、`open_box/bench` 重放、真实模型/搜索、华为云、线上部署均未执行；
  不得用离线结果替代这些验收。
- `safe_http.PublicTransport`（钉住解析结果）已实现但未经真实 TLS 环境验收；
  当前默认路径是"逐跳 URL/DNS 预检 + 模块级 httpx 请求"，真正的防重绑定需要生产出网代理/防火墙兜底。
- 4 项 legacy 旧失败（03/08/30/31）保留：同名异校人工队列契约、读取预算耗尽标记、
  字符串字段兼容、审核改述摘录；不得为通过而放宽身份/原文约束。
- PDF 隐藏文字检测依赖 pdfminer（已列为必需依赖）；缺失旧环境仍会退化为不检测，部署时需重装依赖。

## 产品/工程缺口（未在本轮完成）

- 人工复核尚无前端录入表单（API 与存储已就绪）；候选人限时补证链接、案件转派未实现。
- 结构化论文登记仅白名单元数据字段有 C 级逐要素路径；其他类别字段级充分性策略尚需完善。
- 全部外部 API 尚未统一进安全出网层：论文/GitHub/搜索等固定地址 API 未走 DNS 预检
  （目标是固定域名，风险低，但未统一）；上传类型检测已接入，解析器资源上限仍可加固。
- 网关退出会话后的工作进程内存取消、后台任务完整取消/配额记账策略未完成。
- Bench 仅 10 条合成案例，未冻结旧规则基线、未提供消融与三组对比图；所有指标只能来自合成数据。
- 页面布局与真实浏览器交互未测。
