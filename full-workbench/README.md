## 临时免登录调试

当前比赛工作台的直接入口为 <https://8.208.14.251/ict/>。设置 `UNDERBOX_ICT_DEBUG_GUEST=1` 后，首次访问自动创建独立的浏览器调试会话，无需填写用户名与密码。每个会话默认5次核验、有效期24小时；配额可通过 `UNDERBOX_ICT_DEBUG_QUOTA`（1–50）配置。浏览器各自保留自己的历史，调试用户不能访问管理员配置和其他账户的报告。调试示例始终是虚构资料，不向匿名访客提供队员真实摘录。

管理员入口为 <https://8.208.14.251/ict/?login=1>，仍需原有管理账号。调试用户可用“重置调试”结束当前会话，原历史不会公开给新会话。关闭调试时将该环境变量设为 `0` 并重启 `underbox-ict-full`；现有调试会话随即不能读取 API，正常账户仍可登录。代码默认关闭此开关，运行环境文件不随源码提交。

完整版本有55项临时数据库/合成账户接口测试、30项费用预算与检索增强检查，以及两套Node检查；原适配器保留17项测试。既有规则测试的存量失败仍单独记录，没有为预算控制调整证据判定规则。

## 与赛题二的衔接

AgentArts 中的 UnderboxVerify 负责核心核验工具编排，比赛后端负责原有解析、检索、确定性判定和完整报告。导入、账户、历史和辅助问答继续作为工作台能力。不要把所有辅助 HTTP 请求都标成 AgentArts 调用。

```
浏览器工作台（登录/授权/拆分/勾选）
    → 比赛后端建立一次性、精确范围票据
    → IAM 签名调用已发布 AgentArts 实例
    → Agent 调用 RunUnderbox（submit / status）
    → 独立适配器 → 仅回环私有 broker → 原核验流水线
    → 完整报告仅保留在比赛后端，工具向 Agent 返回报告摘要及 SHA256 回执
    → 后端核对实际任务完成 + 回执，浏览器展示完整报告
```

兼容线上既有协议：submit 仍只有 `action`、`resume_text`、`consent` 三字段。`resume_text` 第一行携带 `UNDERBOX-WORKBENCH/1 wb_…` 传输标识，后续为选中原文；它不是履历经历。适配器识别该保留头并转交私有 broker，必须与服务器票据绑定文本逐字一致。带此头的无效请求直接失败，不回退到旧解析任务。status / delete 的 `wb_` 任务编号也走同一隔离通道。

平台未调用工作台任务、任务失败或回执不匹配时，页面明确失败，不自动改走绕过 AgentArts 的核验。云端摘要、模型思考过程不会作为取证证据展示。重复 submit 对同票据幂等，后台任务不会因浏览器断线重复启动；成功报告与用量会独立保存。

长任务的云端响应提前结束时，后端等待已启动的核验结束，并在同一 AgentArts 会话中只查询原任务的 `status` 来取回真实回执，不重新提交简历。一次请求最多4次云端调用、总等待上限15分钟；达到上限后仍保留本轮任务，可在一小时内按相同拆分、勾选和补充材料重试获取结果。核验报告必须匹配云端实际回执后才展示为成功。

待确认任务保存在独立数据库同目录的 `ict-tasks/` 中，目录权限700、文件600，包含本轮选中摘录及报告/问答上下文，不能加入源码仓库或对外提供。过期文件在后续请求时清理；没有后续请求时可能继续保留至运维清理。已完成任务可在进程重启后恢复；正在执行却被重启中断的任务不自动重跑。成功记录、问答上下文、用量与一次配额在同一数据库事务内保存，同一任务重试不会重复保存或扣配额。

## 隔离与部署

- 原站：`underbox`，原代码和端口保持。
- 比赛完整工作台：`underbox-ict-full`，网关 `127.0.0.1:18905`、工作进程 `18906`、私有工具 broker `18904`。
- 比赛旧简版：`underbox-ict-workbench`，`18902`，保留作为回滚入口。
- 公网只经过现有 HTTPS Nginx；不额外公开新工作端口。
- IAM 凭据：已有 `/etc/underbox-ict/workbench.env`；独立工作台配置 `/etc/underbox-ict/full.env`；模型配置 `/var/lib/underbox-ict-full/models.env`。均不进入源码。
- 适配器仅取得 broker 配置，不取得工作台 DB 或原项目密钥。
- 工作台 DB 与历史：`/var/lib/underbox-ict-full/users.db`，不在源码包内。
- 原账户和其他人的原始简历未复制；样例仅为此前授权的两条赛事摘录，放在独立受限状态目录。
- 工作进程有公网取证出口限制：只允许公共地址的 HTTP/HTTPS；保留已有本地 SearXNG 搜索，阻断私网/元数据探测与非 Web 端口。

部署前安装 `requirements.txt`，配置受限环境文件及独立管理员，执行全量离线回归。生产 Nginx 路径使用 `X-Forwarded-Prefix`，页面资源和 API 路径均随前缀生成。不要把凭据写入 HTML/JavaScript，也不要将原站数据库直接替换为比赛版数据库。

回滚时将 `/ict/` 的 Nginx upstream 改回 `127.0.0.1:18902` 并验证 `nginx -t` 后 reload；旧简版服务及旧 AgentArts 已提交版本均保留。完整版本服务可停止，不需要改动原站。

## 验证结果与限制

见 `VALIDATION.md` 及同包的 `outputs/regression`。原始源码的离线测试已有存量失败，必须单独呈现，不能写成全绿或准确率指标。新增工作台测试使用临时数据库、合成账户与模拟提供方，不调用付费 API。实际两条赛事仅用于连通性演示，不能代表所有文件类型、经历类别或准确率；无公开证据不等于经历不实。语音只做合成 WAV 和模拟提供方验证，未开启真实麦克风。
