# 跨学校推免名单实查与检索调整

检查日期：2026-10-03。

其他学校确实有公开的推免名单，但公示入口、标题和文件格式不同。只搜“姓名 + 推免”或只读取公告 HTML，会漏掉附件中的姓名。找到公示入口也不一定能取得名单全文。

## 已实施的查询顺序

在已识别双方学校、来源院系、入学年度的学生推免陈述中，通常生成以下8条查询。官网限定覆盖学校根域及院系、教务处、研究生招生等子域。

1. 接收方官网：`"姓名"`。
2. 接收方公众号：`"学校" "姓名"`，不强制带推免关键词。
3. 推荐方官网：`"姓名" 推免`。
4. 推荐方官网：`入学年度 免试 资格 名单`，覆盖正式标题。
5. 接收方官网：`入学年度 推免 拟录取 名单`。
6. 推荐方官网：`入学年度 来源院系或专业 免试 名单`。
7. 接收方官网：`入学年度 硕士 拟录取 名单`，覆盖春季总公告中的推免附件。
8. 推荐方官网：`入学年度前一年 推免 公示`，覆盖前一秋季发布的公告。

这些年份是搜索线索，证据仍须核对公告实际届别和本人行。接收方官网的额外`"姓名" 推免`查询在预算有余时补充执行；公众号查询进入默认8次预算，不再被全部名单查询挤掉，也没有增加默认搜索上限。缺少来源学校或院系时，对应查询不会凭空补学校或专业，计划会使用其余可用路径。不同简历画像的预算不同，不保证每种画像都执行8条。

空姓名查询的去引号、放宽域名等备用请求排在其他原始名单路径之后，避免重复变体挤掉整批名单检索。新增上海大学、中南大学、四川大学的已核实官网域名。其他未收录的来源学校会先搜索学校官网，确认唯一域名后在本次报告内缓存；发现失败时保留学校名，不凭学校名称猜网址。

## 页面与附件读取

- 搜索结果按姓名、陈述要素、名单类型、目标年度排序。
- 官网栏目页可以跟进相应年度公示，再进入附件。最多跟进两层，每页最多两个相关链接，与直接搜索结果共用读页和时间预算。
- PDF、DOCX、XLSX按实际文件内容解析；无扩展名的下载地址同时检查附件标签和查询参数。
- 支持高校 WebPlus PDF 播放器的 `pdfsrc` 地址。哈工程本科生院的 [2023年推免资格公示](https://ugs.hrbeu.edu.cn/2022/0926/c2821a297762/page.htm) 正文没有普通附件链接，名单由播放器内嵌；程序已实际识别并读取其 PDF。该公告从 [官网通知归档](https://ugs.hrbeu.edu.cn/2821/list19.htm) 找到，这次归档定位由人工完成，不能据此声称搜索 API 已自动发现公告。
- HTML、DOCX、XLSX表格保留逐行内容；XLSX保留空列，避免姓名与候补/拟录取状态发生列错位。
- 同一链接在本次陈述中去重。没有本人姓名的推免目录页和名单不调用模型提取个人证据；仍可继续跟进附件。
- 验证码、登录限制、失效请求、无法解析的附件记录为读取失败，不能变成“名单没有该人”。

## 证据阶段

接收方就读证明不限于拟录取公示。官网人物介绍、总师班、在读研究生记录、奖学金名单和官方公众号文章均可作为对应就读要素的证据。同名需要结合学校、学院、专业、年级或硕士身份匹配；校外来访、活动嘉宾或合作作者只出现名字时，不能推定其就读于发布学校。

官网公示类仍为A，官网人物/就读报道和带认证主体的公众号原文可为B。公众号名称含学校名不再自动补成学校认证；没有认证信息时仍保留为线索。转载按原始出处去重。

抽取提示已要求区别：本科拟推荐、最终推荐资格、候补/备选/递补、接收方复试、拟录取以及实际入学。本科最终资格与接收方在读记录可以并列展示为组合佐证，仍需区分就读事实和具体入学方式；若官网或公众号原文明确写明本人通过推免/保送进入该校，也可支持入学方式，不强制要求来自招生名单。统考与推免附件分别核对，不能因为总公告含“推免”就混用证据。拆分提示也要求将简历明确自述的入学方式保留为独立要素。

阶段区别和要素摘录目前由模型提示约束，最终身份、来源与状态按规则判断；这轮没有进行真实模型的阶段判断准确率评测，也没有增加独立的确定性阶段判定器。

## 验证与范围

- 使用GPT网页搜索检查官方入口，并用项目的`PageFetcher`和名单链接识别函数实际回读上海大学、中南大学、四川大学、南京大学页面。
- 四川大学XLSX成功解析；中南大学推免下载被识别为验证码限制；南京大学栏目成功定位当年公告，但当前公告没有详细名单内容。
- 推免专项现有16项回归，覆盖下载地址、附件类型、栏目→公告→附件、内嵌PDF、域名边界、未知本科院校发现、查询优先级、读取预算、表格行列关系，以及官网/公众号就读佐证和入学方式的区分。
- 验证命令：`make test PY=../.venv/bin/python`。
- 本轮82项单元测试与33项验收通过；浏览器交互断言因未安装Playwright跳过。
- 本轮没有调用付费GLM搜索接口；GPT检索成功不代表GLM索引必然覆盖同一页面。

当前仍有明确限制：扫描PDF没有OCR、旧版DOC/XLS暂不支持、必须执行JavaScript才能取得附件地址或名单的页面尚未处理、被删除的历史名单无法恢复，也不自动处理验证码或登录。结果应保留未核实，并给出已找到的官方入口及未能读取的原因。
