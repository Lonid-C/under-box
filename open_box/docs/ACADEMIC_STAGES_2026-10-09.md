# 同校学段与奖项独立核验

用户要求本科、硕士、博士同校时不能串证据，就读不能证明获奖。

执行顺序为已勾选的本科条目 → 硕士条目 → 博士条目 → 未写明层次的学历 → 奖项及其他经历。各阶段内保留并行，输出仍维持原条目顺序。前一阶段未找到材料时，标为未证实；不阻止用独立公开材料核对后续阶段，也不自动搜索未勾选的条目。

本科推免资格属于本科阶段；研究生接收/录取、硕博连读转段以及学位授予分别核对。同校也可设置本科来源学校，但来源提示不是录取证明。后续条目只收到此前已证实的学校等要素和出处，不把未证实的学位、年份或就读关系变为获奖事实。

同校不同层次材料不进入当前学历证据。未说明硕/博的“研究生”材料不自动归给硕士或博士。推荐资格不能证明已被研究生学校录取，在读/拟录取不能证明已获得学位。学历关联只复用同学段直接教育记录；奖项、竞赛名单不再反向复制成学历证据。

荣誉和奖学金查询须具有评奖目的，目标学段明确时加入该学段。原文写出的获奖层次、年份作为独立核对要素；未写明层次且同期同校仅有一个明确教育阶段时，只加检索范围提示，不新增获奖事实。重叠期间不猜。

奖项证据必须是本人获得对应奖项的原文或正式名单本人行，核对学校、奖名、学段和已写明的年份。申请资格、招生奖励政策、另一学生的奖项、其他年度、其他学段和拟推荐/候选状态不能冒充已获奖。就读页面没有目标奖名时不调用获奖抽取模型。获奖日期没有公开原文支持时保持未证实。
