# 高教社杯与英语能力大赛搜索修复

检查日期：2026-10-07。本文记录代码改动和真实公开检索结果，不是对某位候选人的获奖结论。

## 已修复的问题

1. **赛事识别缺失或混淆。** 新增全国高等院校（大学生）英语能力大赛 EAEDU，官网为 `eaedu.org.cn`，与全国大学生英语竞赛 NECCS 分开。高教社杯根据简历中的数学建模、数模或成图上下文识别；只有冠名时显示赛事名称有歧义，不猜官网。
2. **过长的精确标题限制召回。** EAEDU 使用“高等院校 英语能力大赛 + 年份 + 获奖名单”；学校数学建模整批查询使用“数学建模 + 年份 + 获奖名单”。简历明确写出省份时，加入省份/省赛词，不从学校名称猜参赛省份。
3. **官网名单入口依赖搜索引擎。** 数学建模先读取已核对的历年结果栏目或对应年度正式公告，跟进附件；省级奖项仍优先学校/省赛名单。EAEDU 配置实测可读的公开 HTTP 官网及2024省赛样例，按年份和省份选择。协议只取维护表或实际链接，不关闭证书校验、不自动降级其他网站。
4. **基础引擎没有有效召回后过早结束。** 每项已识别赛事最多两条原始整批查询（主办方、学校）允许一次 GLM `search_pro` 补查。只有首页、错误年份或教师赛名单也会触发补查；有有效结果就停止升级。其他查询及放宽变体不会因此继续升级。缓存按查询和域名区分，并发访问相同查询时也只补查一次；保留原有全局引擎配置。
5. **读错名单。** 正式赛不使用模拟/练习赛、教师赛道或校内选拔名单。索引中的省份和年份要匹配简历；门户当前显示2026不改变2024条目的年份。候选人摘录中的年份优先于页面通用标题。团队赛果仍需独立成员关联。
6. **读取失败原因不准确。** 公开 PDF 上限由12 MB改为32 MB，Office附件仍为12 MB。扫描 PDF 返回的分页符不算可读文本；超限、扫描/受保护、SSL证书过期分别记录。同次核验中不反复重试已失败的HTTPS证书；已验证的HTTP入口可独立读取。

上述试验使用真实GLM搜索接口和公开页面读取；没有调用模型替候选人作最终获奖认定，也没有使用报名手机号查询个人结果。

## 报告应说明什么

- 找到名单页面：记录来源、比赛年份、赛段及公开方式，继续核对本人条目。
- 名单为图片/扫描件：说明“找到公开名单，但当前文本解析未能识别姓名”，补查学校官网或申请候选人提供证书。
- 往届系统需要额外身份字段：说明具体查询条件；不能把未提交查询时显示的空表或隐藏提示当成失败结果。
- 未找到本人：只表示当前公开证据不足，不表示简历不实。只有主办方明确声明不公开名单时，才写“官网不提供公开获奖名单”。

## 验证与使用

新增离线回归覆盖独立赛事识别、冠名歧义、正式年份、省份筛选、模拟/教师名单排除、空/无效召回补查、并发缓存、扫描分页符和证书失败。

本次 `make test` 通过：215项单元测试、33项验收脚本；环境未安装Playwright，验收中的浏览器交互断言跳过。

运行 `make test`，或 `python -m unittest discover -s tests -q`。测试模块中的串行模型桩按项目既有测试配置运行；并行行为另有回归覆盖。

正在运行的旧Python服务已载入旧模块，文件更新不会刷新其内存。重启服务后重新上传核验，才会生成新逻辑的结果；原有报告不会自动重算。

代码入口：`app/competitions.py`、`data/competitions.json`、`app/strategy.py`、`app/collect.py`、`app/search.py`。赛事目录可用 `python check_competitions.py --render-only` 重新生成。
