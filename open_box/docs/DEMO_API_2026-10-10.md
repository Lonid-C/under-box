# Demo 专用搜索 API

用户确认为 `demo` 与 `demo2` 共用新的智谱搜索密钥，DeepSeek 保留原 API。为避免共享工作进程下修改环境变量导致所有账户使用同一新密钥，新增账户搜索密钥表和每次任务独立的 ContextVar 上下文。网关提供的认证用户 ID 决定密钥，客户端传入的其他账户 ID 会被拒绝；密钥不经过客户端或转发请求头。

专用绑定只改变智谱搜索。已绑定任务的主索引、备用智谱引擎与并发查询使用同一账户密钥；共享 Brave 与自定义端点不用于该账户。未绑定账户继续使用原搜索配置；DeepSeek 配置、账户角色、额度和报告历史保持原有逻辑。单机模式继续使用原环境配置，只有网关工作进程读取账户绑定。

新增测试覆盖三账户并发、嵌套线程池、上下文清理、密钥损坏时禁止回退、伪造身份拒绝、数据库持久化、不向接口泄露密钥、DeepSeek 和全局环境不变。本地及服务器通过 467 项规则测试、28 项服务集成测试，共 495 项；旧验收仍有 5 项已知失败。本地前端检查通过，服务器原前端 `Usage.start` 接口差异仍与发布前一致，未覆盖该前端。

已实际部署并绑定两个 demo 账户。新智谱 `search_std` 连通性检查成功；安装后逐一验证 demo 与其他启用账户的密钥路由、DeepSeek 原配置、认证健康和额度接口，确认会话/配额接口不泄露密钥。剩余核验额度为 `demo` 9 次、`demo2` 10 次；连通性检查未消耗核验次数。其他账户绑定与共享设置保持原值。

服务器备份位于 `/opt/underbox/backups/demo-api-20261010-162333`（服务器时区）。本地实际发布与回归记录保存在 `outputs/demo-api-deployment-result.json`、`outputs/demo-api-server-regression.json`、`outputs/demo-api-frontend-baseline.json`。文档、日志和部署脚本不含真实密钥。
