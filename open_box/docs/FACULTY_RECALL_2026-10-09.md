# 教师经历检索改进（2026-10-09）

针对付妮主页的漏检进行排查，修改的是通用检索与取证流程，没有配置任何特定姓名或个人网址的命中规则。

## 查询按具体事实生成

- 毕业经历先查学校、毕业、作者简介和校友；未写学段时不猜本科、硕士、博士或推免。既有历史年份窗口至 1980 年继续保留。
- 研究生导师查询导师名录、招生及答辩记录；所指导学生的学位不能证明教师本人的学历。
- 著作列表按书名逐本拆分，出版总量独立保留。先检索书名与作者，再查出版社、ISBN、图书馆责任者和书目原文。
- 教学课程、视频、论坛议程与教材出版分别检索；教学活动不再一律当项目经历。

## 空结果和索引覆盖

关键官网查询的空结果先按现有配置补查，再通过另一开放索引检索并在本地严格过滤至原目标域。不会因补查而接受现任机构、输入主页或伪装子域。

书目原文查询使用另一索引，避免几条不同查询重复返回同批商品和百科页面。补查按同一报告的相同查询缓存；额外实际调用正常计入用量，不无限重试。`SEARCH_ENGINE_OPEN_ALTERNATE` 可指定备用开放索引，默认在搜狗与夸克之间选择与主索引不同的一种。

## 阅读与证据约束

图书馆、出版社及明示毕业事实的资料优先回读。双栏出版社 PDF 分栏解析，书名只能关联对应条目的作者，不借相邻书目的责任者。姓名、书名、本人角色、出版总量分别核对；主编、执行主编、共同主编和主持编写不互相代替。

现任机构的渠道排除、本校就读/本校荣誉例外以及同名人员身份门禁继续生效。出版社名称和收藏书目的大学不能变成作者的任职/学历身份。回读失败时沿用已有的搜索摘要标记及降级规则。

## 界面

新增“著作与教材”分组；列表显示当前书名和对应角色，总量另列。原始输入文字和定位仍保留。

本地及服务器暂存副本验证 457 项规则测试、7 项现有服务集成测试；前端用量、查询退出、导航及历史检查通过。新增回归覆盖未明示学位、教材拆分、作者身份、邻书误配、教师学历误认、原官网边界、备用索引、图书馆加载占位页、学科查询词及排除渠道缓存。

发布脚本逐文件比较线上基线 SHA-256 后备份并原子替换；有并发修改或活动工作请求即停止覆盖。重启后检查真实 API 配置、登录账户健康、历史记录和公网前端哈希。此次不修改账户、密钥或既有报告。
