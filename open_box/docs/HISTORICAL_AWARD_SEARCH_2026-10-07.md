# 蓝桥杯与英语能力大赛：历史奖项搜索修复

日期：2026-10-07。此次复现对象来自本地网页中的一份真实简历报告（真实姓名不入库）：2021.07英语能力大赛非英语专业组省赛一等奖，2021.11蓝桥杯算法设计大赛三等奖。用户不知道蓝桥杯的赛段和编程组别，因此保留未知，不改成省赛或国赛。

## 问题与修复

| 问题 | 本次改动 |
|---|---|
| 蓝桥杯官网公告是动态页面，静态回读只有标题 | 按官网前端实际使用的公开GET正文接口读取文章；接口失败单独记录，不把页面空壳当作可读名单 |
| 最新年度回顾不能查2021，公告往往只写届次 | 使用“蓝桥杯”简称、年份、姓名与届次；2021对应第十二届仅用于检索路由，不替简历添加事实 |
| 真正的名单在RAR里，省赛包内还有RAR | 支持ZIP/RAR及两层嵌套，读取包内PDF/DOCX/XLSX；原文件名保留为上下文，不向磁盘展开成员路径 |
| 大包读取其他省份耗尽时间 | 已确认学校的所在地只作为文件选择线索，先读取对应赛区；范围有限，不据姓名未出现作不实判断 |
| 2021英语奖项却读取2024之后的首页/查询系统 | 年份范围纳入预设筛选；早期年份优先学校同期名单和人物报道，不能借2024名单核验2021 |
| 搜索命中其他年份仍浪费读页预算 | 排除明确属于其他赛年/阶段的名单；保留可能包含历史奖项的毕业生人物介绍 |
| 获奖名单是图片，找到了网页却没有姓名 | macOS本机Vision OCR识别正文名单图片，按相邻标题选择学生组，排除Logo、头像和二维码；其他环境无本机OCR时明确报读取限制 |
| 学校网站超时后，已收录的本人摘要也全部丢失 | 有确切候选人姓名的公开搜索摘要可作为单独标记的线索；OCR与摘要不能单独升级为“已证实”，需人工核对原图/原文 |

## 实际读取的官方路径

1. 蓝桥杯[历届获奖名单](https://dasai.lanqiao.cn/notices/860/)通过官网公开正文接口可读，列有第一至第十四届附件。
2. 第十二届[决赛RAR名单包](https://x-static.lanqiao.cn/upload/202110/courseimg/41147d63-c9bb-47d8-ae99-d5776a6c39f8.rar)约8.9 MB，已读取9份软件赛PDF，含C/C++、Java、Python的本科/研究生组，共约35万字符。
3. 第十二届[省赛RAR名单包](https://upload.lanqiao.cn/file/20210608/1623136848170184.rar)约43 MB，含第一场和第二场的嵌套RAR。已读取黑龙江软件赛两场名单。按赛区选择后，名单包解析实测约2.4秒；下载耗时另计。
4. 哈尔滨工程大学[2021省赛获奖公示](https://qihang.hrbeu.edu.cn/2021/0918/c3225a275340/page.htm)可被公开搜索索引发现，原站在本次网络环境下连接超时；部分其他历史公告跳转统一认证，不能绕过。
5. 英语大赛[2024广东省赛公告](http://eaedu.org.cn/news-106.html)的非英语专业组图片已实测OCR，读出姓名、学校、省份、组别与奖级。该样例只验证图片读取能力，不用于证明2021奖项。
6. 英语大赛当前公开首页/往届系统未提供此次可直接读取的2021对应入口。继续补查学校官方来源；不会将当前门户空表或错误年份名单当作本人结果。

## 本人核验结果与边界

目前未找到足以证明上述两条2021自述的本人获奖记录。已读的蓝桥杯决赛软件赛以及黑龙江省赛两场文本中未匹配到候选人姓名；这是本次已读范围的结果，不意味着所有赛道、赛区或其他算法赛均已穷举，也不证明简历不实。

真实GLM学校/官网搜索与页面回读也未形成足够证据。引擎返回链接数量不作为成功标准；必须读取正确年份、正确比赛的本人条目。蓝桥杯还缺具体赛段、组别或证书，英语2021记录还需历史名单或学校官方佐证。

## 运行与验证

- 243项单元回归通过，33项验收脚本通过；环境未安装Playwright，浏览器交互断言跳过。
