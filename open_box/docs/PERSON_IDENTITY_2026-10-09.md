# 同名人员证据准入修复

问题复现：输入是 2023 年起香港中文大学（深圳）音乐学院钢琴表演本科在读，选中 2024 祥波书院毕业晚宴学生工作；检索却把厦门大学 2025-07-14 拟聘决议中“海洋与地球学院：助理教授 唐思”放进证据栏，只有“时间吻合”信号。旧规则只对有现任单位的人启用姓名以外的锚点要求，学生会直接放行。

修改：

- 每条陈述都接收整份输入的姓名、学历学段/期间、专业院系、当前及过去任职上下文。未勾选的学历仍参与身份约束。上下文仅用来限定取证，不把自述当成已证实事实；优先用原文明示学段，模型猜测的机构/作品不作身份锚点。
- 搜索回读后检查本人记录，模型摘录后再次检查，规则判定/复用证据时再检查。姓名、发布时间、可信域名、模型身份分和用户提供的链接都不能单独放行。
- 在本科在读期间显示助理教授等教师职称、或已在读硕士博士，且输入没有可关联的进阶学历/教师经历时，排除出证据。不把导师或指导者的职称误算成学生职称；保研资格、拟录取与已经在读仍分开。允许有明确教师任职的第二学位，以及毕业后的职业变化。
- 本人行学校明确不匹配时排除；不从页脚、导航或名单里另一人的行借学校。混合页面可以抽取正确的本人行，最终摘录不能混入错配记录。完整姓名有边界，唐思远/王唐思不等于唐思。
- 保留有学校、任职或本条具体经历锚点的记录；注册学校及本次查询确认的学校域名按同一份查询上下文使用。模型声称“学校一致”等信号不直接计分，改用规则从本人摘录核对出的信号。团队赛果与专用 GitHub API 记录保持各自的身份与证明范围。
- 日志说明为何排除来源；报告说明姓名/发布时间相同不等于本人。旧历史报告保留原记录；新核验使用新门禁。

验证包含截图原例、同校助理教授、模型伪造身份分/学校/学段、同名及近似姓名、页脚和邻行误借身份、博士生错配、真实本科名单、真实教师的历史学历、升学资格、第二学位、导师身份与候选人身份分离、未勾选学历约束，以及原有主页来源、GitHub、学段和账号隔离回归。
